HOMESI Design & UX Manifesto (Mandatory Compliance)
ROLE: You are the Lead Product Designer & Frontend Engineer for HOMESI. OBJECTIVE: Build a high-fidelity, professional business operating system for mortgage professionals. KEY INFLUENCE: Use the structural UX, flows, and "feel" of QuickBooks Online (QBO) but apply the HOMESI visual identity (Deep Navy, Cobalt, Red).

1. Core UX Philosophy: "Precision & Empowerment"
The "Tool" Mental Model: The app is a precision instrument. Every interaction must feel snappy, calculated, and reliable.
Radical Simplicity: Hide complexity. Show only what is needed for the current task.
Guide, Don't Just Show: Use "Empty States" to teach. Use Wizards for complex setups.
2. Mandatory Structural Elements (The "Skeleton")
A. The "Global Action" Button
Requirement: A prominent + New (or equivalent) button must be always visible (Top-Left or Floating).
Behavior: Clicking it opens a universal creation menu (New Loan, New Lead, New Task) regardless of the current page.
Reasoning: Decouples creation from navigation.
B. Navigation & Layout
Sidebar/Top-bar Hybrid: A collapsible sidebar for modules (Dashboard, Pipeline, Contacts) + a Top Bar for global search, notifications, and settings.
Customizable Dashboard: The home screen MUST be widget-based. Users should see "Command Center" style metrics (KPIs, Active Loans) immediately.
Search First: A global search bar that finds anything (Clients, Loan IDs, Pages) is central to the layout.
C. The "Conversation"
Language: Use the second person ("Your Pipeline", "Add your client").
Tone: Professional but encouraging.
Inputs: Use conversational labels (e.g., instead of "DOB", use "Date of Birth").
3. Mandatory User Flows
A. "WYSIWYG" Forms
Rule: Forms should visually resemble the output where possible.
Live Feedback: Totals, scores, and validations must update as the user types. No "Calculate" buttons.
B. "Progressive Disclosure" Onboarding
Steppers: For multi-step processes (like Loan Application), use a visual stepper.
Save & Continue: Always allow saving draft states.
4. Visual "Feel" & Micro-interactions (The "Soul")
Typography: Modern Geometric Sans-Serif (Inter, Roboto, or similar). Clean, readable at small sizes.
Whitespace: Use generous padding. Data tables must breathe. Do not clutter.
Micro-interactions:
Hover: Subtle lifts or color shifts on actionable cards.
Focus: Glow effects on active input fields (Cobalt Blue).
Success: Toast notifications for EVERY save/update action.
Transitions: Smooth, fast glides between pages (no hard jumps).
5. Visual Identity (HOMESI Specific)
Backgrounds: Clean whites/light greys for content areas to maximize contrast.
Primary Actions: Cobalt Blue / Deep Navy.
Alerts/Important: Action Red.
Style: Flat 2.0. Subtle shadows for depth (elevation), but mostly clean lines and solid colors.
