# Protocol
State-Aware User Guidance.

# Instruction
Autonomously design and implement "Hints" (tooltips) and "Warning Messages" across all UI components, even if the developer omits them.

# State Logic
If a process (like a Reward Scheme) requires approval, generate proactive alerts: "You have [X] pending approvals in your Queue. Action required to activate Strategy."

# Language Constraint
ALL UI text, notifications, and technical documentation MUST be in 100% English at all times.
